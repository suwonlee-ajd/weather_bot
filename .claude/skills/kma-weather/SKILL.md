# 기상청 예보 조회

기상청 날씨누리 공개 페이지에서 예보를 가져온다. **API 키도 결제도 필요 없다.**

자세한 자료 구조와 파싱 근거는 [`docs/forecast-format.md`](../../../docs/forecast-format.md) 참고.

## 조회

```bash
.venv/bin/python -m src.query            # 전국, 이번 주
.venv/bin/python -m src.query 부산        # 지역 지정
.venv/bin/python -m src.query 제주 --week-offset 1 --json
```

| 인자 | 설명 |
|---|---|
| `region` | 광역 구역 또는 도시명. 생략하면 전국 |
| `--week-offset 1` | 다음 주 |
| `--json` | 기계용 JSON |

## 답할 때 — 날씨 자체를 먼저

**사용자가 알고 싶은 것은 "그래서 날씨가 어떤가" 이다.** 확률·수치를 앞세우지 말고
하늘상태와 기온부터 말한 뒤, 확률은 뒤에 덧붙인다.

- ✅ "수요일은 맑고 낮 최고 30도까지 오릅니다. (강수확률 10%)"
- ❌ "수요일 강수확률 10%, 기온 13~30도입니다."

비가 관건인 날은 예외다 — 비가 오는지가 그날의 날씨 자체이므로 먼저 말한다.

- 수치는 기상청 원문이므로 그대로 옮긴다. **추정해서 채우지 않는다.**
- 태풍·특보는 예보관 서술(`□`/`○` 줄)에 있다. 거기 없으면 "해당 없음"이라고 답한다.
- 조회가 실패하면 지어내지 말고 실패했다고 말한다.

## 읽는 법 — 기온은 '지역 간 분포 범위'다

`아침 14~22℃` 는 하루의 최저/최고가 **아니다.** 전국 각지의 아침 최저기온이 14℃에서
22℃ 사이에 걸쳐 있다는 뜻이다. 낮 기온도 마찬가지다. 이 의미를 뒤집어 말하지 않는다.

`[통보문]` 은 D+0~D+3, `[중기예보]` 는 D+4~D+10 에서 온 값이다.

## 조회 범위

| 단위 | 범위 | 성격 |
|---|---|---|
| 행정동 | 오늘 ~ **3일** | 값 (기온·하늘상태) |
| 광역 구역 | 오늘 ~ **10일** | 값 |
| 1개월 전망 | **4주** | **확률** (평년 대비 높/비슷/낮음 %) |

10일 너머는 `src/outlook.py` 가 1개월 전망을 가져온다. **값이 아니라 확률**이라는 점을
반드시 함께 전한다 — "평년보다 높을 확률 50%" 이지 "몇 도"가 아니다.
그보다 먼 요청(내년, 3개월 이상)은 기상청도 예보하지 않으므로 거절한다.
과거 날씨도 다루지 않는다(예보가 아니라 관측이다).

## 지역

```
전국 · 수도권 · 강원 · 영서 · 영동 · 충남 · 충북 · 전남 · 전북 · 경남 · 경북 · 제주
```

- `서울`·`부산`·`청주`·`여수` 같은 도시명도 해당 구역으로 해석된다.
- `중부`·`남부`·`영남`·`호남`·`충청` 은 대응하는 기상청 페이지가 없어 대표 구역으로
  보낸다. 이때 **무엇으로 바꿔 읽었는지 안내문이 함께 나오므로 사용자에게 그대로 전한다.**
  (`영동`·`영서` 는 중기예보가 실제로 나눠 주는 구역이라 안내문이 없다)
- 못 알아듣는 지역은 종료코드 2 와 함께 안내가 나온다. **임의로 가까운 지역을 고르지 말고
  사용자에게 되묻는다.**

## 동 단위 조회

```bash
.venv/bin/python -c "
from src.dong import search_dong, fetch_dong
hits = search_dong('역삼동')          # 후보를 점수순으로
z, n = hits[0].code, hits[0].full_name
f = fetch_dong(z, n)
for d, lo, hi, sky, pop in f.daily_summary():
    print(d, f'{lo:.0f}~{hi:.0f}℃', sky, pop)"
```

- `search_dong()` 은 후보 목록, `find_dong()` 은 가장 가까운 하나를 돌려준다.
  행정동코드 10자리를 직접 줘도 된다 (`1168064000` = 서울 강남구 역삼1동).
- **후보가 여럿이면 하나로 단정하지 말고 사용자에게 되묻는다** — 강릉에도 강남동이 있다.
  `서울 강남` 처럼 시/도나 시군구를 앞에 붙이면 좁혀진다.
- 못 찾으면 빈 목록이다. 가까운 동으로 추측하지 말고 광역 구역을 안내한다.

## 지상일기도

```bash
.venv/bin/python -c "
from src.kma_chart import fetch_latest_chart
c = fetch_latest_chart('surf')
open('/tmp/chart.png','wb').write(c.png)
print(c.label, c.url)"
```

`surf` 지상일기도, `ghmd_s24` 24시간 예상일기도. 00/12 UTC(09시/21시 KST) 두 번만
발표되고 약 2일치만 보관된다.

## 알아둘 것

- 같은 수집 코드를 매주 월요일 슬랙 게시 봇(`src/post.py`)과 멘션 봇(`src/mention.py`)이 함께 쓴다.
- 주 중간에 `--week-offset 0` 으로 조회하면 지난 요일은 "예보 없음"으로 나온다. 정상이다.
- 강수확률은 D+0~D+3 구간에 없을 수 있다. 통보문에 그 값이 없기 때문이며, 비워 두는 것이 맞다.
- 조회가 실패하면 `logs/{연}/{연.월}/{앱}.error.{날짜}.log` 에 질문 원문과 함께 남는다. 읽는 법은 [`docs/logging.md`](../../../docs/logging.md).
