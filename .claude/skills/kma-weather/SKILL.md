# 기상청 예보 조회

기상청 날씨누리 공개 페이지에서 예보를 가져옴. **API 키도 결제도 필요 없음.**

자세한 자료 구조와 파싱 근거는 [`docs/forecast-format.md`](../../../docs/forecast-format.md) 참고.

## 조회

```bash
.venv/bin/python -m src.query            # 전국, 이번 주
.venv/bin/python -m src.query 부산        # 지역 지정
.venv/bin/python -m src.query 제주 --week-offset 1 --json
```

| 인자 | 설명 |
|---|---|
| `region` | 광역 구역 또는 도시명. 생략하면 전국 |
| `--week-offset 1` | 다음 주 |
| `--json` | 기계용 JSON |

## 답할 때

가져온 자료를 문장으로 옮기는 기준은 **[`weather-reply`](../weather-reply/SKILL.md)**
스킬에 있음. 조회한 뒤 그쪽을 따라 씀.

여기서도 지켜야 할 것 하나 — 수치는 기상청 원문이므로 **그대로 옮김.**
추정해서 채우지 않고, 조회가 실패하면 지어내지 말고 실패했다고 말함.

## 읽는 법 — 기온은 '지역 간 분포 범위'

`아침 14~22℃` 는 하루의 최저/최고가 **아님.** 전국 각지의 아침 최저기온이 14℃에서
22℃ 사이에 걸쳐 있다는 뜻. 낮 기온도 마찬가지. 이 의미를 뒤집어 말하지 않음.

`[통보문]` 은 D+0~D+3, `[중기예보]` 는 D+4~D+10 에서 온 값.

## 조회 범위

| 단위 | 범위 | 성격 |
|---|---|---|
| 행정동 | 오늘 ~ **3일** | 값 (기온·하늘상태) |
| 광역 구역 | 오늘 ~ **10일** | 값 |
| 1개월 전망 | **4주** | **확률** (평년 대비 높/비슷/낮음 %) |

10일 너머는 `src/outlook.py` 가 1개월 전망을 가져옴. **값이 아니라 확률**이라는 점을
반드시 함께 전함 — "평년보다 높을 확률 50%" 이지 "몇 도"가 아님.
그보다 먼 요청(내년, 3개월 이상)은 기상청도 예보하지 않으므로 거절함.
과거 날씨도 다루지 않음(예보가 아니라 관측임).

## 지역

```
전국 · 수도권 · 강원 · 영서 · 영동 · 충남 · 충북 · 전남 · 전북 · 경남 · 경북 · 제주
```

- `서울`·`부산`·`청주`·`여수` 같은 도시명도 해당 구역으로 해석됨.
- `중부`·`남부`·`영남`·`호남`·`충청` 은 대응하는 기상청 페이지가 없어 대표 구역으로
  보냄. 이때 **무엇으로 바꿔 읽었는지 안내문이 함께 나오므로 사용자에게 그대로 전함.**
  (`영동`·`영서` 는 중기예보가 실제로 나눠 주는 구역이라 안내문이 없음)
- 못 알아듣는 지역은 종료코드 2 와 함께 안내가 나옴. **임의로 가까운 지역을 고르지 말고
  사용자에게 되물음.**

## 동 단위 조회

```bash
.venv/bin/python -c "
from src.dong import search_dong, fetch_dong
hits = search_dong('역삼동')          # 후보를 점수순으로
z, n = hits[0].code, hits[0].full_name
f = fetch_dong(z, n)
for d, lo, hi, sky, pop in f.daily_summary():
    print(d, f'{lo:.0f}~{hi:.0f}℃', sky, pop)"
```

- `search_dong()` 은 후보 목록, `find_dong()` 은 가장 가까운 하나를 돌려줌.
  행정동코드 10자리를 직접 줘도 됨 (`1168064000` = 서울 강남구 역삼1동).
- **후보가 여럿이면 하나로 단정하지 말고 사용자에게 되물음** — 강릉에도 강남동이 있음.
  `서울 강남` 처럼 시/도나 시군구를 앞에 붙이면 좁혀짐.
- 못 찾으면 빈 목록. 가까운 동으로 추측하지 말고 광역 구역을 안내함.

## 지상일기도

```bash
.venv/bin/python -c "
from src.kma_chart import fetch_latest_chart
c = fetch_latest_chart('surf')
open('/tmp/chart.png','wb').write(c.png)
print(c.label, c.url)"
```

`surf` 지상일기도, `ghmd_s24` 24시간 예상일기도. 00/12 UTC(09시/21시 KST) 두 번만
발표되고 약 2일치만 보관됨.

## 단풍 (9월 둘째 주 ~ 11월 둘째 주)

```bash
.venv/bin/python -m src.query --foliage            # 21개 명산 전체
.venv/bin/python -m src.query --foliage 설악산      # 한 산 (별칭 '설악' 도 됨)
.venv/bin/python -m src.query --foliage --json
```

- **현황은 기상청 관측, 날짜 예상은 웨더아이**. 기상청은 단풍 시기를 예보하지 않음.
  출력의 `관측`/`예상` 표시를 그대로 옮기고 둘을 섞지 않음. 문장 기준은 `weather-reply` 의 단풍 절.
- 기간 밖이면 종료코드 3 과 다음 기간이 나옴. **그때는 단풍을 답하지 않음.**
- 기상청이 관측하는 21곳에 없는 산은 종료코드 2. 가까운 산으로 대신하지 말고 21곳을 안내함.
- 산 날씨는 `src/mountains.py` 의 `zone`(산 아래 탐방 거점 행정동)으로 위 동네예보 조회를 씀.
- 꽃 개화(벚꽃·진달래 등)는 다루지 않음.

## 알아둘 것

- 같은 수집 코드를 매주 월요일 슬랙 게시 봇(`src/post.py`)과 멘션 봇(`src/mention.py`)이 함께 씀.
- 주 중간에 `--week-offset 0` 으로 조회하면 지난 요일은 "예보 없음"으로 나옴. 정상.
- 강수확률은 D+0~D+3 구간에 없을 수 있음. 통보문에 그 값이 없기 때문이며, 비워 두는 것이 맞음.
- 조회가 실패하면 `logs/{연}/{연.월}/{앱}.error.{날짜}.log` 에 질문 원문과 함께 남음. 읽는 법은 [`docs/logging.md`](../../../docs/logging.md).
